# UML-Class-Diagram-Blokus
## 1st deliverable for the **Object-Oriented Programming** course (March 2022) Object-oriented analysis and UML modeling of the Blokus board game.
The main objective of this project was to design a **UML Class Diagram** that modeled the main entities of the Blokus game, including the **game board, players, human and computer-controlled players, game pieces, rounds, scoring system, and special action cards**. The diagram defined the attributes and methods of each class, as well as the relationships, associations, and multiplicities between them.

The UML Class Diagram was designed using **StarUML 4.0.1**.
